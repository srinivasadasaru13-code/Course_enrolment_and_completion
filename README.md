# Course-Enrolment-and-Completion-analysis

Interactive Power BI dashboard built on Excel-cleaned data, analyzing 500 e-learning users to surface completion rates, dropout drivers, and engagement trends across platforms and course types.

📊 Project Overview
This project analyzes data from 500 learners across 11 attributes to understand why students complete, abandon, or stay stuck in online courses — and translates those findings into actionable retention strategies.

🛠️ Tools Used
Excel — data cleaning, validation, and structuring
Power BI — data modeling, DAX calculations, and interactive visualization

🔄 Process
Collect — Gathered raw learner data (500 records, 11 attributes)
Clean — Validated and structured data in Excel (course type, platform, completion status)
Analyze — Explored completion rates, dropout reasons, and engagement patterns
Visualize — Built an interactive Power BI dashboard with column, pie, and donut charts

🔍 Key Insights
Only 31% of learners fully completed their courses, revealing a significant retention gap.
"Time Constraint" and "Too Difficult" are the top dropout drivers, together accounting for 72% of all dropout cases.
Completion rates are nearly flat across 5 platforms (Coursera, edX, Udemy, Skillshare, YouTube) and 3 experience levels (Fresher, Student, Working Professional) — meaning the platform isn't the problem.
Hours spent per week shows almost no correlation with completion, suggesting course design, not learner effort, drives dropout.

✅ Recommended Solution
Redesign courses into shorter, modular lessons with adaptive difficulty checkpoints to directly target the top two dropout drivers. Since platform and hours spent showed little impact on completion, focus improvement efforts on course structure and pacing rather than platform choice.
